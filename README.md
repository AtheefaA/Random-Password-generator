# 🔐 Random Password Generator

## 📌 Project Overview

The **Random Password Generator** is a Java-based application that generates strong and secure random passwords. It helps users create passwords containing a combination of letters, numbers, and special characters, improving security for online accounts and applications.

This project demonstrates Java programming concepts such as random number generation, string manipulation, and user interaction.

## 🚀 Getting Started

### Prerequisites

* Java JDK 8 or above

### Installation

1. Clone or download this repository.
2. Navigate to the project folder.
3. Compile the Java source file:

```bash
javac RandomPasswordGenerator.java
```

4. Run the program:

```bash
java RandomPasswordGenerator
```

---

## 📖 How to Use

1. Run the application.
2. Enter the desired password length (if applicable).
3. The program generates a random secure password.
4. Copy and use the generated password safely.
